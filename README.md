# STM32 Peripheral Labs

Hands-on STM32 Nucleo F401RE peripheral experiments using 
STM32CubeIDE and HAL library.

## Hardware
- STM32 Nucleo F401RE (STM32F401RE)

## Peripherals

|----------|------------|-------------|
| 01_GPIO  | GPIO + LED blink (HAL + register level) | ✅ Done |
| 02_UART  | UART printf via USART2 at 115200 baud   | ✅ Done |
| 03_SPI   | SPI + OLED display                      | 🔄 Upcoming |
| 04_I2C   | I2C sensor interface                    | 🔄 Upcoming |
| 05_ADC   | ADC potentiometer reading               | 🔄 Upcoming |
| 06_Timers| Timers + PWM                            | 🔄 Upcoming |
| 07_DMA   | DMA for UART                            | 🔄 Upcoming |
